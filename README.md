# DUMIK Codex 插件市场

这是 DUMIK 团队共用的 Codex 插件市场仓库。

## 当前插件

- `dumik-team-plugin`
- 版本：`0.1.0`
- 内容：图片提示词、改图指令、高级图像提示词、电商视频转化策划、连续分镜提示词

## 团队安装方式

在 Codex 里打开“添加插件市场”，填写：

- 来源：本仓库地址
- Git 引用：`main`
- 稀疏路径：留空

安装后搜索 `DUMIK Team Plugin` 即可使用。

## 更新规则

更新插件时同步修改 `plugins/dumik-team-plugin/.codex-plugin/plugin.json` 里的版本号，并重新提交到 `main`。
