# 项目入口与环境协议（唯一来源）

项目入口、项目目录、归档规则、环境部署和工具检查的唯一权威文档。`agent-skill-routing.md`、`ecom-visual-director`、`tvc-director` 都引用这里，不再各写一份。改规则只改本文件。

## 项目入口协议

项目制不是默认强制开启，先看用户意图和当前项目指针（仓库根 `CURRENT_PROJECT.md`）。

- 无 `CURRENT_PROJECT.md`，且用户要项目制、批量、多轮沉淀、确认图/片后批量：先问项目名，以及图片项目 / 视频项目 / 混合项目。
- 已有 `CURRENT_PROJECT.md`，且用户没有要求切换：默认沿用当前项目，不再重复问项目名。
- 用户明确说切换项目：确认新项目名和项目类型，更新 `CURRENT_PROJECT.md`，并把切换记录写入 `CONTEXT.md`。
- 用户明确说不进入项目：本次按单次任务处理，不修改 `CURRENT_PROJECT.md`，产物不强制归当前项目。
- 用户只要一句提示词、一次改图、一次单图/单条生成，且没有项目制表达：按单次任务处理，不要为了“完整”强行建项目。

## 项目目录

默认根路径 `project\<项目名>\`。图片项目目录由 `D-image-run\scripts\init_project.py` 创建，视频项目由 `D-video-run\scripts\init_project.py` 创建。三大入口目录必须保持兼容底层脚本：

```text
project\<项目名>\
  原图\
  参考\
  输出\
    提示词\
    确认图\      # 图片项目
    确认片\      # 视频项目
    成品\        # 图片项目
    成片\        # 视频项目
    运行记录\
    临时\
```

混合项目同时允许 `确认图 / 确认片 / 成品 / 成片`。不要在顶层另开项目子目录；产物分类只放在 `输出` 内。

## 归档规则

- 待处理图片、首帧、分镜图、关键帧放 `原图`。
- 产品 / 材质 / 场景 / 风格 / 结构参考、参考视频、参考音频放 `参考`。
- 上游提示词、任务 JSON、提示词记录、视频脚本、逐镜提示词放 `输出\提示词`。
- 确认产物放 `输出\确认图`（图）/ `输出\确认片`（片）。
- 用户确认后的正式结果放 `输出\成品`（图）/ `输出\成片`（片）。
- 运行记录、run-state、提交 ID、队列状态、错误记录、参数记录放 `输出\运行记录`。
- 裁切、压缩、抽帧、转码、联系表等中间文件放 `输出\临时`，不混进成品/成片。
- Eagle、本地素材库、飞书画板等外部素材默认只读引用；除非用户明确要求，不复制、不移动、不写回原素材。

## 环境部署时机

满足任一条就先部署项目环境，再调度底层技能：

- 用户明确说项目制、批量、多张、整组、成套、先出确认图/片、确认后批量、提交 Dreamina / Veo。
- 实际生图/生视频且后续会继续沉淀素材或多轮返修。
- 任务包含多类素材：原图、参考、提示词、确认产物、成品和运行记录。

## 检查清单复用

全量环境检查不要每次重复做。先读 `assets\verified-environment-checklist.md`：

- 清单版本与当前插件版本匹配时，复用清单结论，不重复检查插件结构、脚本存在性、Python、FFmpeg、Dreamina 和敏感信息扫描。
- 只做本次项目级检查：项目目录、分类目录、输入文件、提示词 JSON、参考素材、输出路径。
- 实际调用接口前，再轻量确认动态项：API 缓存、本次权限、Dreamina 登录 / Veo 权限、FFmpeg（需裁切转码时）、Banana2 本地参考图的 tunnel URL 可达性。

## 工具检查

进入实际生成、批量、项目制前检查：

- Python 可运行；对应执行 skill 的 `init_project.py` / `generate_batch_images.py` / `generate_batch_videos.py` 存在。
- 接口配置可读：优先本机 `CODEX_HOME\dumik-team-plugin\api_settings.py`；没有时运行插件根 `scripts\init_api_cache.py` 初始化；仍没有再读 `CODEX_HOME\config.toml`、`CODEX_HOME\auth.json` 和环境变量。
- Dreamina 路线：`dreamina` CLI 可用，提交前先看对应子命令 help。
- 需要本地参考图公网 URL 时：NAS 发布配置或临时 tunnel 脚本可用。

## 自动修复边界

能自动修复的直接做，不烦用户：

- 缺项目目录或 `输出` 内分类：创建补齐。
- 缺 API 缓存但本机配置存在：运行 `scripts\init_api_cache.py`。
- 缺 Python 依赖且有明确依赖文件或脚本报缺模块：当前环境安装后重验。
- 缺 FFmpeg 且本机包管理器可用：自动安装后重验。

不能自动处理才停下说明缺口：

- 缺 API key / token；Dreamina 未登录、额度不足或需网页确认；Veo / NewAPI 缺权限。
- 没有可用公网参考图发布路径，且 Banana2 必须读本地参考图。
- 安装需要登录、管理员权限或外部账号确认。
- 视频参考超平台限制，且自动裁切会改掉用户想保留的关键内容。

## 最小提问规则

只问会卡住下一步的问题：项目入口缺失问项目名和类型；改图缺目标图问哪张；生成缺模型或完整提示词问缺项；视频缺时长/比例/主卖点且影响镜头结构时只问缺的关键项。其余能从当前项目、素材记录或语境判断的，不重复问。
