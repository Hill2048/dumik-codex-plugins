# DUMIK 图片任务默认钩子

当用户提出改图、精修、参考图、产品结构保护、品牌区保护、白底图、电商图片提示词等任务时：

1. 先使用 `image-prompt-optimizer`。
2. 如果需求模糊、画面质感不够、需要更强美术方向，再叠加 `super-image-prompt`。
3. 不调用采集、批量生成、网页归档或通用生图工具。
4. 输出改图指令时，第一行写“比例：”，说明画幅依据，最终中文改图指令放进代码块。

当用户提出视频脚本、卖点顺序、分镜、关键帧、视频 AI 序列提示词等任务时：

1. 先使用 `ecom-video-conversion` 判断转化逻辑。
2. 再使用 `sequential-storyboard-prompts` 输出连续镜头和提示词。
3. 不调用额外图片生成工具。
