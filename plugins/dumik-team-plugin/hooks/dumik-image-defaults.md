# DUMIK 图片任务默认钩子

当用户提出改图、精修、参考图、产品结构保护、品牌区保护、白底图、电商图片提示词等任务时：

1. 先使用 `image-prompt-optimizer`。
2. 如果需求模糊、画面质感不够、需要更强美术方向，再叠加 `super-image-prompt`。
3. 默认只写提示词、brief 或改图指令，不调用采集、批量生成、网页归档、通用生图工具或图片接口。
4. 输出改图指令时，第一行写“比例：”，说明画幅依据，最终中文改图指令放进代码块。

当用户明确提出生图、出图、生成图片、编辑图片、调用 JuAIHub 或调用图片接口时：

1. 使用 `image-batch-agent` 的单图模式。
2. 生成前确认已经有可执行提示词、输入图和输出位置。
3. 生图前选择模型：`gpt-image-2` 或 `banana2`。`banana2` 会提交为 `nano-banana-2`。
4. 公开版插件不内置 API Key。优先运行 `scripts/init_api_cache.py` 写入本机缓存；没有缓存时再读 `CODEX_HOME/config.toml`、`CODEX_HOME/auth.json` 和环境变量。
5. 如果用户只是要提示词、brief 或改图指令，不调用图片接口。
6. 只有用户明确说“批量 / 多张 / 整组 / 项目制 / 批量生成”时，才切到 `image-batch-agent` 批量模式。

当用户提出视频脚本、卖点顺序、分镜、关键帧、视频 AI 序列提示词等任务时：

1. 先使用 `ecom-video-conversion` 判断转化逻辑。
2. 再使用 `sequential-storyboard-prompts` 输出连续镜头和提示词。
3. 默认只写脚本、分镜和视频提示词，不调用额外图片或视频生成工具。

当用户明确提出产品故事板、Image2 故事板、产品身份板、产品故事板生图提示词或逐镜生视频提示词时：

1. 使用 `product-storyboard-video-prompts`。
2. 输出产品变量表、Image2 产品身份板提示词、Image2 产品故事板提示词、分镜拆解表和逐镜生视频提示词。
3. 默认只输出提示词，不提交图片或视频生成任务。

当用户明确提出批量生视频、批量视频生成、项目制生视频、先出确认片或用即梦批量提交视频任务时：

1. 使用 `video-batch-agent`。
2. 先确认项目名、输出路径、比例、时长、参考素材角色和是否使用默认模型。
3. 创建项目后暂停，让用户放首帧/分镜图和参考素材。
4. 先出 1 条确认片，用户确认后再批量提交。
5. 真实提交前提醒会消耗 Dreamina 额度。

当用户提出批量改图、批量图片修改、项目制批量提示词等任务时：

1. 使用 `image-batch-agent`。
2. 先确认项目名、输出路径、改图目标和参考图角色。
3. 默认只写逐图改图提示词，不生图、不出确认图、不调用图片接口。
4. 只有用户明确说“生图 / 出图 / 生成图片 / 调用接口 / 先出确认图 / 批量生成”时，才在批量模式里先出 1 张确认图，用户确认后再批量生成。
5. 公开版插件不内置 API Key。优先使用本机缓存；运行时 `--api-key` 和 `--base-url` 可临时覆盖；不能打印 key 或 token。
6. 明确出图前先选择模型：`gpt-image-2` 或 `banana2`。
7. 明确出图后，可使用 `output_size` 控制单条输出尺寸，使用 `--concurrency 1-8` 控制并发。
