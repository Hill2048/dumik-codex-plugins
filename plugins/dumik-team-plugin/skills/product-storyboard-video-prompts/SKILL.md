# 产品 Image2 故事板 + 逐镜生视频

## 职责边界

只做三件事：

1. 从产品资料抽变量。
2. 按 Image2 规范写产品身份板和故事板生图提示词。
3. 把故事板拆成逐镜生视频提示词。

不做：

- 不重新设计转化链路；需要卖点顺序时先用 `ecom-video-conversion`。
- 不写泛化连续分镜；非产品或非 Image2 的连续镜头用 `sequential-storyboard-prompts`。
- 不提交图片/视频生成任务；用户明确要求生成并确认额度后再调用对应工具。

## 输出顺序

默认输出这 5 块，用户只要其中一项时只输出对应项：

1. 产品变量表
2. Image2 产品身份板提示词
3. Image2 产品故事板提示词
4. 分镜拆解表
5. 逐镜生视频提示词

## 产品变量表

先抽变量，再写提示词。

```text
产品名称：
外观结构：
材质颜色：
核心卖点：
使用场景：
视觉风格：
故事板整体比例（16:9 / 9:16）：
单格分镜比例（默认 3:4）：
分镜数量：
不能改变的产品特征：
禁止出现的内容：
```

变量规则：

- `外观结构` 写轮廓、比例、关键部件。
- `材质颜色` 写材质、表面、反光、透明度、颜色。
- `核心卖点` 最多 3 个，按画面优先级排序。
- `故事板整体比例` 只在故事板生图提示词里使用，默认支持 `16:9`、`9:16` 两种。
- 产品电商故事板默认整体为 `9:16`，每个分镜小格默认按 `3:4` 画面比例组织。
- `不能改变的产品特征` 是所有后续提示词的身份锚点。

## Image2 身份板提示词

用途：锁产品身份，减少后续分镜和视频漂移。

```text
创建一张艺术性的 16:9 产品身份板。

主体：{产品名称}
外观结构：{外观结构}
材质颜色：{材质颜色}

背景为纯白色或柔和米白色；无环境、无道具、无标志、无水印。

创建电影感、高端、艺术书式的产品身份板，不要做机械参数表。
布局不对称、优雅、有大片留白；避免网格、蓝图、目录式排版和重复视角。

放置一个大型产品英雄主视角作为视觉锚点。
围绕它排列辅助研究：正面、侧面、俯视、关键结构、材质细节、开合状态、使用状态。

所有视角保持严格一致：
相同轮廓、相同比例、相同材质、相同颜色、相同关键结构。
不要改变：{不能改变的产品特征}

添加简约产品 ID 信息块，仅使用：名称、品类、核心卖点、视觉标志。
风格：简约、电影感、高端、干净、适用于后续图像和视频制作。
```

## Image2 故事板提示词

用途：锁镜头、动作、产品身份和剪辑连续性。故事板不是海报合集，也不是带字幕的宣传图，而是视频蓝图。

## API 提示词与执行层分离

写给 Image2 生图 API 的 `final_instruction` 只放画面语言，不放执行说明。

`final_instruction` 应该只包含：

- 简短画布 / 版式描述，例如 `12 格产品故事板，3 列 × 4 行`。
- 参考图角色，每张参考图只写它控制什么。
- 画面表现和 12 个动作节点。
- 极少量最关键的画面风险提醒。

不要写进 `final_instruction`：

- `输出规格`、`原生生成`、`尺寸 2160x3840`、`4K`、`Image2 规范` 等 API 参数。
- `提交生成时必须把...作为参考`、文件路径、素材上传方式、命令、模型名、并发数、输出路径。
- 长串 `严格禁止`、营销口号、后期字幕、参数卖点、执行备注。
- 可以用参考图解决的场景、色调、材质和人物细节，不要反复用文字描述。

这些内容放到执行表、JSON 字段或报告备注里：

- `output_size`
- `file`
- `reference_files`
- 素材提交清单
- 后期字幕 / 口播 / 卖点说明
- 连续接力依赖关系

## 连续故事板引用规则

如果某张故事板写“继承上一张”“承接上一段”“接上一张第 12 格”“从上一张结尾开始”，必须把上一张已选故事板图作为真实参考图写进提示词和执行输入。

- 参考名固定用 `@PREV_STORYBOARD_REF`。
- `@PREV_STORYBOARD_REF` 只控制第 01 格的主体位置、光线方向、焦点、场景延续和上一张结尾状态。
- SB01 没有上一张时不写 `@PREV_STORYBOARD_REF`。
- SB02-SB05 或任何后续故事板，凡是依赖上一张结尾，都必须在“参考图角色”里写清 `@PREV_STORYBOARD_REF`。
- 只在文字里写“继承 SB01 / 接上一张”，但生成时没有传上一张故事板图，不算连续接力。
- 在 API 提示词里只用一句简短参考角色说明连续性，不要写“提交生成时必须把...”这类执行提醒。
- 如果执行工具/API 不能传上一张图，必须删掉“继承上一张”的承诺，改成“按文字设定保持连续感”，并明确告诉用户连续性会弱。

示例：

```text
参考图角色：@PREV_STORYBOARD_REF 承接上一张结尾的主体位置、光线和焦点；@PRODUCT_REF 锁定产品结构；@ACTION_REF 控制手部动作。

01 依据 @PREV_STORYBOARD_REF 继承 SB01 第 12 格的锅盖旋钮和红色阀门微距，手部从画外靠近。
```

故事板比例规则：

- `16:9`：横版故事板，适合横版广告片、官网视频、横屏产品片。
- `9:16`：标准竖版故事板，适合电商产品视频、短视频平台、信息流和移动端观看。
- `3:4`：默认用于每个分镜小格的画面比例，不作为整张故事板默认输出比例。
- 用户没指定时：产品电商故事板默认整张用 `9:16`，每个小格按 `3:4` 构图；明确是横版成片时整张用 `16:9`。

默认画面规则：

- 故事板画面里可以出现简洁分镜序号、镜头运动箭头和少量专业标注，用于导演和生成执行识别；标注必须克制、清楚、像专业分镜稿。
- 标注规范：
  - 箭头：用红色实线标注运动方向，箭头长度表示速度，长箭头代表快，短箭头代表慢。
  - 方框：用蓝色虚线标注位置 / 区域，并标注中心点坐标，例如“方框 1 中心 (x:300,y:400)”。
  - 数字：用白色粗体标注时序，例如“1→2→3”；也可以标注角色 ID，例如“角色 A=1，角色 B=2”。
- 不要出现卖点文案、营销字幕、参数堆叠、水印或乱码字。
- 可以保留克制的镜头引导线 / 构图引导线 / 运动箭头 / 区域框 / 时序数字，但不要使用廉价贴纸箭头、发光流线、能量波、科技 HUD、蓝图线框或过度标注。
- 运动和功能证明要靠构图、景别、产品状态、手部动作、蒸汽、真实光影和镜头连续性表达。
- 如果需要给用户说明镜头，可在提示词文本或报告里写清楚，不要要求模型把说明文字画进图里。

```text
12 格产品故事板，3 列 × 4 行。

参考图角色：@SCENE_REF 控制场景和光线；@PRODUCT_REF 锁定产品结构和材质；@ACTION_REF 控制手部 / 食物 / 功能动作；@MOTION_REF 只参考镜头路径和剪辑节奏。

画面表现：{一句话说明本镜头目的和可见证明}。氛围参考 @SCENE_REF，产品结构参考 @PRODUCT_REF，少量镜头箭头和分镜序号即可。

12 格连续动作：01 {动作节点}；02 {动作节点}；03 {动作节点}；04 {动作节点}；05 {动作节点}；06 {动作节点}；07 {动作节点}；08 {动作节点}；09 {动作节点}；10 {动作节点}；11 {动作节点}；12 {结尾定格}。

保留白色粗体分镜序号 01-12，可加少量细红色运动箭头和克制蓝色虚线构图框。不要画营销文字、水印或乱码；产品结构跟参考图一致。
```

## 分镜拆解表

拿到故事板后，把每格拆成视频可执行字段：

```text
镜头编号：
画面目标：
起始画面：主体位置、景别、构图
主体动作：只保留一个主动作
镜头运动：只保留一个镜头动作
环境变化：只保留一个辅助变化
结束画面：最后停在哪里
生视频注意事项：
```

如果某格信息不清楚，写 `需重画该格`，不要硬猜。

## 逐镜生视频提示词

每格一条，不要把所有镜头塞进一条提示词。

```text
使用 @PRODUCT_REF 保持产品身份一致，使用 @STORYBOARD_REF 的第 {镜头编号} 格作为画面来源，生成 {时长} 秒视频片段。

身份锚点：
产品是 {产品名称}，外观结构为 {外观结构}，材质颜色为 {材质颜色}。不要改变 {不能改变的产品特征}。

起始画面：
从第 {镜头编号} 格的构图开始，主体位置是 {主体位置}，景别是 {景别}。

主体动作：
{主体动作}

镜头运动：
{镜头运动}

环境变化：
{环境变化}

结束画面：
停在 {结束画面}，方便衔接下一镜。

限制：
不新增无关部件，不切换场景，不改变产品结构，不出现无关文字或水印。动作克制清晰，一个主动作配一个镜头运动。
```

默认按 `seedance2.0` 的稳定性写提示词；用户明确要快速草稿时再降低镜头复杂度。

## 返修定位

- 主体漂移：回身份板或产品变量。
- 动作错误：改故事板对应格或单镜提示词。
- 镜头乱飞：减少镜头动词。
- 画面太杂：收紧环境限制。
- 出现廉价箭头/粗线条/发光特效：回到故事板提示词，明确写“只保留专业、细、克制的红色实线运动箭头、蓝色虚线区域方框、白色粗体时序数字 / 角色 ID 和构图引导线，不要贴纸箭头、发光流线或装饰线条”。
- 结尾不可接：补结束画面。
