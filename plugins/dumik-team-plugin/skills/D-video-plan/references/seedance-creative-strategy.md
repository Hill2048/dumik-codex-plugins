# Seedance 视频转化策略参考

来源参考：MapleShaw/seedance2.0-prompt-skill，commit a2ab7fd。本文是 DUMIK 电商视频线的消化版，不作为独立入口。

## 使用边界

本文件只补强 `D-video-plan` 的内容策略，不写逐镜提示词，不提交 Dreamina。

用于：

- 商品短视频、投放视频、详情页视频的节奏判断。
- 判断一条视频应该讲一个卖点，还是拆成多条。
- 为后续 `D-storyboard` 提供模块顺序和节奏基准。

不用于：

- 直接生成视频。
- 替代产品身份锁定。
- 把短剧、概念片逻辑套到电商商品上。

## 时长判断

### 4-8 秒

只做一个可见瞬间。适合主图视频、确认片、单卖点试片。

结构：

1. 0-2 秒先给最强可见证据。
2. 2-5 秒展示产品动作或材质变化。
3. 5-8 秒停在记忆画面。

### 9-15 秒

可以做一个完整卖点链路，但不要讲太多。

结构：

1. 开头：痛点或异常画面。
2. 中段：产品介入。
3. 后段：结果证据。
4. 结尾：品牌或品类记忆。

### 15 秒以上

必须拆模块。不要指望一条提示词完成完整内容。

先规划：

- 每段解决一个相信问题。
- 每段有独立可见证据。
- 相邻段之间有衔接点。
- 后续交给 `D-storyboard` 拆镜头，再交给 `D-video-run` 生成。

## 电商优先级

Seedance 通用创意强调 hook；DUMIK 电商线要先满足转化。

排序：

1. 产品是什么。
2. 解决什么痛点。
3. 视觉证据是什么。
4. 和普通竞品差异在哪里。
5. 结尾记住什么。

不要把电影感、美学词、复杂运镜放在产品可信度前面。

## 开头原则

前 2 秒必须有明确观看理由：

- 直接看到痛点，例如划痕、水渍、发霉、变形、难清洗。
- 直接看到反差，例如普通材质失败，对比产品表现稳定。
- 直接看到产品动作，例如开合、旋转、承重、切割、冲洗、收纳。
- 直接看到结果，例如干净、平整、耐用、质感稳定。

避免：

- 纯氛围开场。
- 慢慢推近但没信息。
- 先讲品牌再讲产品。
- 一上来塞多个卖点。

## 模块模板

### 认知型

用于新品类、新材质、新结构。

顺序：

1. 先定义品类。
2. 再展示差异结构。
3. 再给使用理由。
4. 最后落到记忆点。

### 信任型

用于价格高、材质强、用户容易怀疑的产品。

顺序：

1. 先给疑问。
2. 再给实验或生活证据。
3. 再给细节特写。
4. 最后给稳定结果。

### 使用愉悦型

用于厨房、收纳、家居、清洁等高频使用场景。

顺序：

1. 先给使用前的小麻烦。
2. 再给顺手动作。
3. 再给细节反馈。
4. 最后给完成后的舒服状态。

### 差异型

用于竞品多、外观相近的商品。

顺序：

1. 先摆出普通方案的问题。
2. 再展示本品关键结构。
3. 再给对比结果。
4. 最后强化“为什么是它”。

## 剪辑节奏

短视频可以借用六类节奏，但要转成电商语言：

- 呼吸式：快展示痛点，慢停产品证据。适合大多数详情页视频。
- 心跳式：反复靠近关键细节。适合强功能、强质感产品。
- 海浪式：一层层增加使用场景。适合生活方式和套装。
- 子弹时间：在关键结果处放慢。适合承重、切割、防水、开合。
- 脉冲式：多场景快切。适合大促、套装、多 SKU。
- 静默锤击：安静画面里突然给强证据。适合高端、极简、质感型产品。

## 输出给 D-storyboard 的信息

交接时至少保留：

- 视频用途：主图 / 详情页 / 投放 / 内容。
- 时长建议。
- 比例建议。
- 模块顺序。
- 每个模块的画面任务。
- 必须保留的产品身份特征。
- 哪些卖点删掉或后置。
