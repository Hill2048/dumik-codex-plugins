# 高清修复工作流

这是一个**两次生图 + 一次本地处理 + 一次提示词反推**的固定流程。不要跳步骤，不要把它改写成普通改图。

## 适用情况

- `image2` / `banana` 系列图片反复修改后变脏、发灰、边缘糊、材质脏、细节丢失。
- 用户明确要“去渍”“恢复高清”“按那篇公众号的方法来”。

## 固定四步

### 第一步：提取线稿

必须先调用 `image-batch-agent` 的真实执行脚本，把原图转成干净黑白线稿。

- 目标：固定造型、结构、边缘。
- 默认模型：`image2`
- 默认画质：自动换算为合法的 `image2` 尺寸（长边 2048）
- 线稿提示词要强调：
  - 只保留黑白两色
  - 线条干净流畅
  - 去掉杂色、渐变、灰脏感
  - 保持原图结构和比例不变

### 第二步：提取固有色

不要生图。直接对原图做本地高斯模糊，默认半径 `10`，产出固有色参考图。

- 目标：保留大色块、固有色、整体光影关系。
- 默认输出：和原图同尺寸的 `solid-color-blur.png`

### 第三步：反推提示词

基于原图反推一份中文提示词，重点提取：

- 主体和造型
- 材质
- 光影
- 色调
- 场景或背景
- 构图与镜头感

如果用户已经给了可用提示词，优先复用并轻量补全，不要强制重写。

### 第四步：高清修复

再次调用 `image-batch-agent` 的真实执行脚本，输入：

- 原图
- 第一步线稿图
- 第二步固有色图
- 第三步反推后的中文提示词

最终修复提示词要明确：

- 按图片1还原线稿结构
- 按图片2恢复固有色和光影
- 保持主体造型和比例稳定
- 输出高清、干净、无脏污、无灰感、边缘清晰的最终图

默认模型和参数：

- 默认模型：`image2`
- 默认画质：自动换算为合法的 `image2` 尺寸（长边 2048）
- 用户明确要更高档位时：再单独指定更大的合法 `image2` 尺寸

## 执行入口

优先执行脚本：

`scripts/run_image_repair_hd_workflow.py`

最小调用形态：

```powershell
python scripts\run_image_repair_hd_workflow.py `
  --image "<原图路径>" `
  --output-dir "<输出目录>"
```

可选参数：

- `--reverse-prompt "<已有中文提示词>"`
- `--lineart-model image2|banana|bananapro`
- `--final-model image2|banana|bananapro`
- `--final-size 944x2048` 这类合法尺寸；不传时 `image2` 自动按原图比例换算
- `--blur-radius 10`
- `--subject "<主体补充说明>"`

## 输出要求

结果目录至少要有：

- `01-lineart.png`
- `02-solid-color-blur.png`
- `03-reverse-prompt.txt`
- `04-final-prompt.txt`
- `05-final.png`
- `repair-run.json`

## 交接规则

- 真正生图一律复用 `image-batch-agent` 脚本，不重写接口层。
- 如果用户只要方案不要执行，可以只输出四步结果和最终提示词，停在文字层。
- 如果用户要继续批量跑，再交给 `image-batch-agent` 或更上层自动编排。
