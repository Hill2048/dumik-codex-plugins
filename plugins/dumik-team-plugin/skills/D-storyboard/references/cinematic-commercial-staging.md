# 高级商业电影调度

用于高级广告、TVC、品牌片、电影感产品片、真人实景剧情、导演感分镜和反 AI 质感。它增强 `product`、`hybrid`、`sequential`，不替代模式选择，也不改变 `D-video-plan` 已确定的卖点顺序。

## 核心立场

高级广告不是“去商业化”。商业目标、产品证据和品牌记忆必须成立；要拒绝的是廉价广告模板：油亮棚拍、无来源轮廓光、全局青橙或蜂蜜金、英雄摆拍、平均照亮、堆砌粒子和只靠昂贵布景制造价值。

电影语言的工作是让产品更可信、更有重量、更值得记住：

- 用摄影机立场控制观众如何发现卖点。
- 用空间和人物关系制造观看压力。
- 用动作展示产品介入和结果。
- 用物理光色证明材质与使用环境。
- 用因果剪辑把转化链变成可见事件。

当电影语言与产品真实性冲突时，保护同一 SKU、结构、材质、比例、关键部件、品牌区和真实功能；不得为了构图或氛围静默改产品。

## 开拍前五个决定

### 1. 可见障碍

把抽象情绪或营销话术改成可以拍到的事实。

- 不写“高级、治愈、有品质”。
- 写“湿滑台面让普通器具不断移位，本品在同一动作下保持稳定”。
- 写“厨房已经收拾完成，只有一件笨重器具无法进入狭窄收纳位”。

产品片没有人物冲突时，障碍可以是材料、空间、时间、动作失败或普通方案的局限。

### 2. 摄影机立场

每镜先回答：

- 观众站在哪里，为什么能看到这一刻？
- 是使用者视角、旁观验证、受限窥视、台面见证，还是空间外的冷静观察？
- 产品、人物、环境或规则，谁在画面里拥有更大力量？

机位由观看关系产生，再决定景别、焦段、角度和遮挡。前景只有在解释机位、延迟信息、表现距离或导向证据时才保留。

### 3. 视线流量

内部为每镜写一行：

```text
视线从入口进入，被某个结构或动作减速，落在唯一关键证据，再由动作方向或空间线条带走。
```

电商镜头的落点应优先是产品、关键部件、真实动作或结果。若视线最后落在无关布景、灯光或人物表情上，重新构图。

### 4. 物理光色

先定颜色来自哪里，而不是先套调色：

- 主色域：墙体、台面、服装、天气或大面积材料。
- 辅助色域：自然反射或相邻空间。
- 强调色：产品识别、关键部件、火焰、指示灯或动作结果。
- 主光源：窗、顶灯、灶火、冰箱灯、工作灯、车灯或其他可见/可推断光源。

同组镜头只保留一个主要成像方向，如干净真实数字电影、35mm 发行拷贝、16mm 纪录质感或早期数字视频。缺陷要局部、克制，不使用全局脏污和统一颗粒贴纸。

### 5. 信息密度

每镜默认只保留：

- 一个主要动作或卖点证据。
- 一个次要线索。
- 一个主要构图决定。
- 一个主光源，最多一个自然反射或辅助实景光。
- 两到三个决定性场景信息。

高端不等于每个角落都昂贵、锐利和精彩。允许普通过渡镜头、暗部、遮挡、失焦和留白，只要不影响产品识别与证据阅读。

## 镜头账本

生成故事板前先建立：

```text
镜号：
镜头功能：
主要动作 / 产品证据：
观众位置：
景别 / 机位 / 焦段：
构图压力：
视线入口 / 落点 / 出口：
物理光源与色彩来源：
次要线索：
与前镜变化：
```

连续镜头至少有真实变化。可从景别、机位高度、距离、主体与环境比例、观看立场、构图机制、焦点层、光向、人物状态中选择。不要固定套“远景—中景—特写”，也不要让所有镜头都是中近景慢推。

## 因果结构

### 高级商业片

按实际时长压缩，不要求固定九镜：

```text
观看理由 / 可见障碍
-> 产品或品牌进入
-> 决定性动作
-> 结构或材质证据
-> 可见结果
-> 差异或信任强化
-> 产品 / 品牌记忆
```

交换镜头后仍不影响理解，通常说明只是漂亮画面合集。检查：障碍是否让产品介入变得必要，动作是否产生证据，证据是否支持结果，结果是否收束到正确记忆。

### 九镜剧情或品牌故事

可使用：规则、发现、物理证据、压力、决定、位置变化、后果、代价、开放余韵。`product` 和 `hybrid` 中必须把产品功能自然嵌入决定与证据，不能让剧情吞掉产品。

## 比例调度

- `21:9`：横向关系、左右对照、空间压迫和画外延伸。
- `16:9`：动作与环境均衡，适合横版成片。
- `9:16`：使用上中下纵深、前后层级和手机安全区，关键产品不要贴上下边缘。
- `3:4` / `4:5`：强化人物或产品与纵向空间关系，保留发布裁切余量。
- `1:1`：使用紧凑关系和四边安全区，避免把横版构图硬裁成方形。

比例变化必须重新安排主体、视线和留白，不是机械裁切。

## 拼版与独立镜头标注

- 三联、四宫格、九宫格及其他分屏拼版，每格按阅读顺序标注 `SHOT 01`、`SHOT 02`……。
- 镜号固定在每格左上角安全区，使用白字和半透明黑底；所有格保持相同字号、边距和底色样式。
- 镜号只属于拼版层。独立镜头、首尾帧和生视频垫图不加镜号或任何版面文字，保持干净。
- 外部拼版时读取干净独立源图，在拼版副本上添加镜号，不覆盖源文件。

## 参考素材角色

- 产品身份参考可以同时锁定结构、材质、颜色和品牌区。
- 动作参考只控制动作路径。
- 构图参考只抽取空间组织和观看关系。
- 光色参考只抽取物理光源与综合色方法。
- 节奏参考只抽取镜头变化和时间密度。

多参考可以协同，但不能互相越权。具体电影、导演或海报只转译成可见的机位、调度、光源、材质和曝光事实，不复制标志性镜头、角色组合、场景骨架或现成 IP。

## 反 AI 与高级商业检查

优先保留：真实演员或可信手部、实景/实体搭景、自然皮肤和材料纹理、可解释光源、有限动态范围、克制锐度、柔和高光滚降、局部光学不完美。

重写以下结果：

- 产品像游戏道具、概念图或塑料模型。
- 皮肤、金属、木材、石材全部同样油亮。
- 无来源边缘光、全局雾、粒子、发光流线和 HDR 代替调度。
- 人物只做模特姿势，产品没有实际动作或证据。
- 布景比产品更抢眼，所谓高级只剩奢侈道具。
- 每镜同一构图、同一动作，仅换角度或焦段。

高级商业画面允许精致、漂亮、干净和明确的品牌控制；这些特征必须建立在真实材质、清晰证据、合理调度和克制光色上，而不是被禁止。
