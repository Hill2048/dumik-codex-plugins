# Seedance 相机编码参考

来源参考：MapleShaw/seedance2.0-prompt-skill，commit a2ab7fd。本文只保留适合 DUMIK 产品视频的镜头语言。

## 使用边界

本文件用于 `D-storyboard` 写分镜、关键帧和逐镜视频提示词。

目标是让镜头可控，不是堆电影术语。

## 一个镜头的最小结构

```text
景别 + 机位高度 + 方位 + 焦段/景深 + 主体动作 + 镜头运动 + 结束画面
```

产品视频必须额外写：

```text
产品结构锁定 + 材质颜色锁定 + 品牌区/关键部件不变
```

## 四个维度

### Z：景别距离

- 大特写：材质、纹理、接缝、五金、品牌区。
- 特写：关键部件动作，如开盖、扣合、切割、冲洗。
- 中近景：产品和手部关系，适合使用演示。
- 中景：产品在台面、厨房、家居空间中的完整状态。
- 远景：环境建立，不适合承担核心卖点。

电商默认从中近景或特写开始，除非视频任务是场景氛围。

### Y：机位高度

- 平视：真实、可信，适合大多数产品。
- 微俯视：台面、厨房、收纳、菜板、餐具常用。
- 微仰视：增强产品力量感，但容易夸张。
- 顶视：展示平面布局、切菜、收纳、组合。

### X：主体方位

- 正面：结构清晰，但立体感弱。
- 四分之三侧：产品视频默认优先，能看清结构和厚度。
- 侧面：展示厚度、轮廓、开合路径。
- 背面：只有当背部结构是卖点时使用。

### F：镜头质感

只写必要信息：

- 50mm 自然视角：默认稳妥。
- 85mm 浅景深：质感特写。
- 微距：纹理、接缝、材质。
- 深景深：多个部件都要看清。

不要为了“电影感”乱写鱼眼、超广角、过度畸变。

## 运动规则

每个镜头最多一个主体主动作和一条摄影机主轨迹。“一条主轨迹”不等于“只能写一个运镜动词”：真实摄影机可以在同一条弧线或螺旋路径中同时平移、推进、升降、偏航和滚转。判断标准是这些分量是否共享同一目标、轴线、方向和速度曲线，而不是动词数量。

推荐：

- 缓慢推近：强调材质和细节。
- 轻微横移：展示结构厚度。
- 稳定俯拍：展示台面动作。
- 小幅环绕：展示外形，但不要绕太大。
- 固定机位：适合实验、对比、切割、冲洗。

避免：

- 没有共同目标和轴线的推近、上升、环绕同时堆叠。
- 近景无动机大幅环绕。
- 镜头快速乱飞或中途重置方向。
- 一个镜头里塞多个产品动作。

## 复合摄影机轨迹

参考视频里同时发生的运动必须保留。先写主路径，再写附着在这条路径上的方向修正：

```text
主路径：摄影机从哪里出发，沿直线 / 浅弧 / 圆弧 / 螺旋移动到哪里。
观看目标：镜头始终看向什么，是否持续偏航或俯仰修正。
旋转轴：绕主体、垂直轴或镜头光轴；不能只写“旋转”。
画面方向：以观众看到的画面为准，参照物顺时针或逆时针移动。
推进关系：靠摄影机实体接近、焦距变化或二者组合；没有证据不要默认数字变焦。
偏轴与视差：主体是否偏离几何中心，前中后景移动速度有何差异。
速度曲线：缓起 -> 加速 -> 峰值 -> 减速 -> 惯性停留，并标出时间段。
```

可接受：

- `摄影机沿产品前方做浅弧右移，同时轻微推近并向左偏航，使产品持续被跟踪；前景台面比后景墙面移动更快。`
- `摄影机向锅心俯冲时持续沿光轴滚转，推进与旋转同步加速；接近纹理后旋转先减速，推进继续，最后共同缓停。`

不可接受：

- 只写“镜头拉近”，遗漏拉近期间仍持续发生的旋转。
- 把真实同步运动改成“先环绕、再推进”，造成生成结果分段或跳轴。
- 只写“顺时针旋转”但不说明是画面参照物、主体环绕还是摄影机光轴滚转。

## 非线性速度

不要用“慢慢”“快速”概括整段。按可见变化拆成少量阶段：

- 缓起：从静止或低速建立方向。
- 加速：位移、推进或角速度连续增加。
- 峰值：最强运动只占短时间，不贯穿整镜。
- 减速：可让旋转与推进在不同时间开始收速。
- 惯性停留：沿原轨迹自然收住，不反向、不循环、不新增动作。

有视频证据时，以剪辑点和关键帧确定阶段；没有可靠证据时只写相对曲线，不编造角度、倍率和每秒速度。

## 产品镜头默认值

```text
中近景，微俯视，四分之三侧，50mm 自然视角，浅景深不过度，产品位于画面中心偏下，镜头缓慢推近，最后停在关键结构或使用结果。
```

## 按卖点选镜头

- 材质：微距 / 特写 / 慢推近 / 稳定光线。
- 结构：四分之三侧 / 轻横移 / 结束停在结构交界处。
- 耐用：固定机位 / 对比动作 / 结果停顿。
- 清洁：顶视或微俯视 / 连续冲洗 / 结束画面干净。
- 收纳：中景 / 平稳横移 / 展示前后变化。
- 高级感：少动作 / 慢镜头 / 呼吸留白 / 清晰边缘光。

## 自检

写完每镜检查：

- 产品是否完整可认。
- 关键部件是否没有被改。
- 镜头运动是否只有一个。
- 若是复合轨迹，各分量是否共享同一目标和轴线，并明确同时发生。
- 旋转方向是否注明观察口径，速度曲线是否连续而不重置。
- 起始画面和结束画面是否都清楚。
- 相邻镜头是否有衔接，而不是跳成无关画面。
