# 故事板与逐镜模板库

主文件给规则，这里给可直接套用的模板块。只换主体、产品、场景，不改结构。

## Image2 产品身份板

只在作品包含需要稳定身份的产品时使用。目的：在故事板和生视频之前锁定产品身份。

```text
创建一张艺术性的 16:9 产品身份板。

主体：{产品名称}
外观结构：{外观结构}
材质颜色：{材质颜色}

背景为纯白色或柔和米白色；无环境、无道具、无水印。

创建电影感、高端、艺术书式的产品身份板，不要做机械参数表。
布局不对称、优雅、有大片留白；避免网格、蓝图、目录式排版和重复视角。

放置一个大型产品英雄主视角作为视觉锚点。
围绕它排列辅助研究：正面、侧面、俯视、关键结构、材质细节、开合状态、使用状态。

所有视角保持严格一致：
相同轮廓、相同比例、相同材质、相同颜色、相同关键结构。
不要改变：{不能改变的产品特征}

添加简约产品 ID 信息块，仅使用：名称、品类、核心卖点、视觉标志。
风格：简约、电影感、高端、干净、适用于后续图像和视频制作。
```

## 故事板生图提示词模板

```text
{N} 格{产品/场景/连续镜头}故事板，{列数} 列 × {行数} 行。

参考图角色：@MAIN_REF 锁定主体身份；@SCENE_REF 控制场景和光线；@ACTION_REF 控制动作；@MOTION_REF 只参考镜头路径和剪辑节奏。

画面表现：{一句话说明本段视频目的和可见证明}。保持主体、光线、空间逻辑连续。

连续动作：
01 {起点画面和动作节点}；
02 {与 01 相连的变化}；
03 {动作推进}；
...
{N} {结尾定格，方便接下一镜}。

每格按从左到右、从上到下的阅读顺序标注 `SHOT 01`、`SHOT 02`……镜号固定在每格左上角安全区，使用清晰白字和半透明黑色矩形底；所有格的字号、边距和样式一致。可加少量专业运动箭头和构图框，不要画营销文字、水印或乱码。
```

## 独立生产关键帧模板

```text
生成一个独立镜头画面，用于后续生视频垫图。只生成单张画面，不生成拼版、宫格、分镜表或接触表。

画面内容：{本镜唯一动作或产品证据}
主体与产品锚点：{必须保持不变的特征}
摄影机与构图：{实体机位、景别、焦段、观看立场和证据落点}
光色与环境：{物理光源、色彩来源、决定性场景信息}

保持画面干净：不加 SHOT 镜号、数字序号、字幕、说明文字、箭头、边框、水印或任何版面标注。
```

独立镜头后续组成三联、四宫格、九宫格或其他拼版时，只在拼版层为每格添加 `SHOT NN`；不得修改或覆盖独立源图。

## 高级商业电影增强模板

当用户要求高级广告、TVC、品牌片、电影感或导演感时，把本块合并进故事板，不替代产品身份与卖点顺序。

```text
商业目标：{观众最终要理解、相信或记住什么}
可见障碍：{不用情绪词，写成能够拍到的产品/人物/空间事实}
高级商业原则：保持产品清楚、真实、可购买；拒绝廉价广告模板，不拒绝精致和商业表达。

物理光色：主色来自 {现实来源}，辅助色来自 {现实来源}，小面积强调色用于 {产品/部件/结果}；主光源来自 {窗/灯/灶火/工作灯等}。
成像方向：{干净真实数字电影 / 35mm / 16mm / 早期数字等一种}，只保留克制、局部的光学不完美。

逐镜账本：
01｜功能 {观看理由/认知/疑问/证据/决定/后果/记忆}；主要动作或证据 {唯一信息}；观众位置 {摄影机为何在这里}；构图压力 {空间/人物/产品关系}；视线 {入口 -> 减速/阻断 -> 产品证据落点 -> 出口}；与前镜变化 {具体变化}。
...

每镜只保留一个主要动作或产品证据、一个次要线索、一个主要构图决定、一个主光源和 2-3 个决定性场景信息。不要油亮棚拍、无来源轮廓光、全局青橙或蜂蜜金、英雄摆拍、平均照亮、过度 HDR、CG 游戏感、蜡质皮肤、装饰性烟雾粒子。
```

## 承接上一张故事板（短例）

```text
参考图角色：@PREV_STORYBOARD_REF 承接上一张结尾的主体位置、光线和焦点；@PRODUCT_REF 锁定产品结构；@ACTION_REF 控制手部动作。

01 依据 @PREV_STORYBOARD_REF 继承上一张第 12 格的主体位置，手部从画外靠近。
```

## 逐镜生视频提示词 — product / hybrid

```text
使用 @IDENTITY_REF 保持主体身份一致，使用 @STORYBOARD_REF 的第 {镜头编号} 格作为画面来源，生成 {时长} 秒视频片段。

身份锚点：
{主体 / 产品身份锚点}。不要改变 {不能改变的特征}。

起始画面：
从第 {镜头编号} 格的构图开始，主体位置是 {主体位置}，景别是 {景别}。

主体动作：
{主体动作}

镜头运动：
{镜头运动}

观众位置与证据落点：
摄影机位于 {实体位置和观看立场}，视线最终落在 {产品动作/结构/材质/结果}。

环境变化：
{环境变化}

结束画面：
停在 {结束画面}，方便衔接下一镜。

限制：
不新增无关部件，不切换无关场景，不改变主体身份，不出现无关文字或水印。动作克制清晰，一个主动作配一个镜头运动。
```

## 逐镜生视频提示词 — sequential

```text
基于 @STORYBOARD_REF 的第 {镜头编号} 格生成 {时长} 秒视频片段。
保持同一主体、同一空间逻辑、同一光线方向和色调。
起始画面为 {起始画面}。
主体动作是 {主体动作}。
镜头运动是 {镜头运动}。
摄影机位于 {实体位置和观看立场}，视线最终落在 {决定性信息}。
环境变化是 {环境变化}。
结束在 {结束画面}，与下一镜保持可衔接。
不要字幕、水印、跳切、身份漂移或无关元素。
```

## 线性连续序列（单条长描述）

```text
同一主体在同一空间中连续运动：从 {起点} 开始，镜头 {镜头运动 1}，主体 {动作 1}；随后 {动作 2}，环境 {变化 2}；最后镜头 {结束运动} 停在 {结尾画面}。保持 {身份锚点}、{光线}、{材质/角色特征} 一致，不出现文字、水印或身份漂移。
```
