# 故事板与逐镜模板库

主文件给规则，这里给可直接套用的模板块。只换主体、产品、场景，不改结构。

## Image2 产品身份板

只在作品包含需要稳定身份的产品时使用。目的：在故事板和生视频之前锁定真实 SKU，不借身份板重新设计产品。

### 参考图角色与顺序

写提示词前先逐张定义参考角色。执行工具支持有序参考图时，顺序固定为：

1. `@MASTER_PRODUCT_REF`：唯一完整产品实拍，必须放第一张，最高优先级；控制整机轮廓、比例、视角关系、部件数量、连接方式和品牌区。
2. `@DETAIL_REF_*`：局部实拍，只校正被点名的部件、工艺或局部材质；不得据此重构整机。
3. `@MATERIAL_REF_*`：只提供表面反射、粗糙度、透光或颜色依据；不得复制其产品造型、场景和文字。

若没有完整产品实拍，不把局部图拼想成整机；明确身份依据不足。重画、返修和并发候选都重新使用同一组原始实拍参考，除非用户明确选定某张生成图作为新基准，否则禁止把 AI 生成结果继续垫图。

### 产品与材质锁定

- 先按区域写清 `部件 -> 材质 -> 颜色 -> 表面粗糙度/反射行为`，不要用“高级、金属感、极致质感”代替可见事实。
- 对镜面金属明确写出深色环境反射带、亮色软箱反射带、窄亮边和连续曲面高光，并排除磨砂、拉丝、灰雾、塑料感和全表面平均发亮。
- 相邻材质必须能被肉眼区分。例如锅具可分别锁定：外壁高反射镜面不锈钢；内壁低反射钛色缎面银灰；透明玻璃；哑黑隔热件。禁止把内外壁合并成同一种灰色金属。
- 黑色要有实体密度，白色高光不能过曝吞轮廓；整体黑白层次明确、通透立体、不发灰，同时保留材质中间调。
- 品牌区只保留主参考图中真实可确认的标识、位置和方向。未提供准确文字时宁可不生成文字；禁止编造品牌、英文、参数、卖点或装饰字符。

### 版式与执行

- 默认只放一个完整英雄产品作为身份锚点，辅助区只展示同一 SKU 的 2-4 个必要局部研究，不生成第二款产品或重复整机。
- 辅助局部必须服务后续连续性，如顶视轮廓、侧视支撑、连接五金、开合状态或材质反射；删除无意义的重复视角。
- 用户要求 `xN` 时，执行层创建 N 条独立任务，每条 `count: 1`、唯一 id 和输出名；每条都传入同一组原始参考，不串联上一张候选。
- 身份板用于确认，不自动成为后续唯一垫图。只有结构、品牌区和材质全部通过后，才能作为故事板身份参考。

```text
创建一张艺术性的 16:9 产品身份板。

主体：{产品名称}
主参考：@MASTER_PRODUCT_REF 是唯一完整 SKU 身份依据，最高优先级。
局部参考：{逐项写 @DETAIL_REF_* 只校正什么；不得影响什么}
材质参考：{逐项写 @MATERIAL_REF_* 只控制什么表面属性}

整机结构锁定：{轮廓、比例、部件数量、连接关系、不能改变的结构}
分区材质锁定：{部件 A -> 材质/颜色/反射；部件 B -> 材质/颜色/反射}
品牌区锁定：{真实标识、位置、方向；没有可靠依据则不生成文字}

背景为纯白色或柔和米白色；无环境、无道具、无水印。

创建电影感、高端、艺术书式的产品身份板，不要做机械参数表。
布局不对称、优雅、有大片留白；避免网格、蓝图、目录式排版和重复视角。

放置一个大型产品英雄主视角作为视觉锚点。
围绕它只排列 2-4 个必要辅助研究：{顶视/侧视/关键结构/材质细节/开合状态中实际需要的项}。
只出现一个完整产品；辅助区是同一 SKU 的局部研究，不生成第二款产品或另一套部件。

所有视角保持严格一致：
相同轮廓、相同比例、相同材质、相同颜色、相同关键结构。
不要改变：{不能改变的产品特征}

文字策略：{只使用用户明确提供且可核对的文字；否则完全不生成文字}。
禁止新增品牌、英文、参数、卖点、装饰字符、乱码或水印。
风格：简约、电影感、高端、干净、适用于后续图像和视频制作。
```

### 身份板验收

按以下顺序检查，前一项失败就不把该图作为身份参考：

1. 完整英雄产品是否与 `@MASTER_PRODUCT_REF` 为同一 SKU：轮廓、比例、部件数量、连接关系和关键结构一致。
2. 局部参考是否只影响指定区域，没有把局部提手、盖子或五金扩散成整机设计。
3. 每个材质区域是否与提示词一致，相邻材质是否有明确视觉区分，镜面反射是否真实而非灰亮塑料。
4. 品牌区是否准确；是否出现虚构文字、错误方向、额外零件或第二款产品。
5. 画面是否清晰、黑白层次明确、不过曝、不发灰，辅助研究是否必要且与英雄产品一致。

并发候选逐张验收并固定编号，不以文件返回顺序代替候选编号。全部失败时从原始实拍重写约束后重跑，不在失败候选上继续修。

## 故事板生图提示词模板

```text
{N} 格{产品/场景/连续镜头}故事板，{列数} 列 × {行数} 行。

参考图角色：@MAIN_REF 锁定主体身份；@SCENE_REF 控制场景和光线；@ACTION_REF 控制动作；@MOTION_REF 只参考镜头路径和剪辑节奏。

画面表现：{一句话说明本段视频目的和可见证明}。保持主体、光线、空间逻辑连续。

连续动作：
01 {起点画面和动作节点}；
02 {与 01 相连的变化}；
03 {动作推进}；
...
{N} {结尾定格，方便接下一镜}。

每格按从左到右、从上到下的阅读顺序标注 `SHOT 01`、`SHOT 02`……镜号固定在每格左上角安全区，使用清晰白字和半透明黑色矩形底；所有格的字号、边距和样式一致。可加少量专业运动箭头和构图框，不要画营销文字、水印或乱码。
```

## 独立生产关键帧模板

```text
生成一个独立镜头画面，用于后续生视频垫图。只生成单张画面，不生成拼版、宫格、分镜表或接触表。

画面内容：{本镜唯一动作或产品证据}
主体与产品锚点：{必须保持不变的特征}
摄影机与构图：{实体机位、景别、焦段、观看立场和证据落点}
光色与环境：{物理光源、色彩来源、决定性场景信息}

保持画面干净：不加 SHOT 镜号、数字序号、字幕、说明文字、箭头、边框、水印或任何版面标注。
```

独立镜头后续组成三联、四宫格、九宫格或其他拼版时，只在拼版层为每格添加 `SHOT NN`；不得修改或覆盖独立源图。

当用户要求高级广告、TVC、品牌片、电影感或导演感时，把本块合并进故事板，不替代产品身份与卖点顺序。

```text

高级商业原则：保持产品清楚、真实、可购买；拒绝廉价广告模板，不拒绝精致和商业表达。

物理光色：主色来自 {现实来源}，辅助色来自 {现实来源}，小面积强调色用于 {产品/部件/结果}；主光源来自 {窗/灯/灶火/工作灯等}。

逐镜账本：
01｜功能 {观看理由/认知/疑问/证据/决定/后果/记忆}；主要动作或证据 {唯一信息}；观众位置 {摄影机为何在这里}；构图压力 {空间/人物/产品关系}；视线 {入口 -> 减速/阻断 -> 产品证据落点 -> 出口}；与前镜变化 {具体变化}。

每镜只保留一个主要动作或产品证据、一个次要线索、一个主要构图决定、一个主光源和 2-3 个决定性场景信息。不要油亮棚拍、无来源轮廓光、全局青橙或蜂蜜金、英雄摆拍、平均照亮、过度 HDR、CG 游戏感、蜡质皮肤、装饰性烟雾粒子。
```

## 承接上一张故事板（短例）

```text
01 依据 @PREV_STORYBOARD_REF 继承上一张第 12 格的主体位置，手部从画外靠近。
```
