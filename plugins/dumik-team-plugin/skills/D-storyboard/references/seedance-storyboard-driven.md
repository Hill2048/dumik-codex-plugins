# Seedance 分镜板驱动参考

来源参考：MapleShaw/seedance2.0-prompt-skill，commit a2ab7fd。本文用于 DUMIK 的故事板和多宫格参考图转视频。

## 使用边界

用于用户给分镜板、故事板、多宫格图、漫画式参考图，并要求转成视频提示词。

只分析分镜和写提示词，不执行生成。

## 先判断模式

### D-1：单条多段

适合：

- 2-4 格。
- 总时长不超过 15 秒。
- 各格属于同一个连续动作。

输出一条带时间段的视频提示词。

### D-2：多条独立

适合：

- 5 格以上。
- 总时长超过 15 秒。
- 每格是独立镜头或信息点。

输出每格一条视频提示词，再给剪辑顺序。

## 最重要的规避

如果参考图是分镜板，必须写清：

```text
只参考每格画面内容和动作节奏，不复刻分镜板的边框、网格线、格子编号、注释文字、UI、水印。
```

否则模型可能把格线、编号、箭头当成画面元素。

## 分镜板分析格式

```text
分镜板类型：2格 / 4格 / 9格 / 12格 / 其他
建议模式：D-1 / D-2
整体比例：
每格内容：
连续性关系：
产品身份锚点：
需要忽略的板面元素：
建议视频比例：
建议总时长：
```

## 每格拆解

每格必须拆成：

- 主体。
- 起始状态。
- 主动作。
- 镜头运动。
- 环境变化。
- 结束状态。
- 与上一格的关系。
- 产品不能改变的特征。

看不清的格子写“需重画该格”或“需用户补充”，不要脑补。

## D-1 模板

```text
比例：9:16，时长：12 秒。参考@图片1中的分镜内容，只提取每格动作和构图，不复刻边框、格线、编号、注释文字或水印。保持同一个产品SKU、材质、比例和关键部件不变。
0-3秒：第1格内容...
3-6秒：第2格内容...
6-9秒：第3格内容...
9-12秒：第4格内容...
全片光线、场景、产品身份保持一致，镜头运动克制，每段只保留一个主动作。
```

## D-2 模板

```text
镜头 01：
比例：9:16，时长：5 秒。参考@图片1第1格的主体关系，不复刻分镜板边框、编号、文字。...

镜头 02：
比例：9:16，时长：5 秒。参考@图片1第2格的主体关系，不复刻分镜板边框、编号、文字。...
```

然后给：

```text
剪辑顺序：
节奏建议：
需要重画或补充的格子：
```

## 电商产品额外规则

- 产品外形以产品身份参考为准，不以分镜板里画歪的形状为准。
- 分镜板负责动作和构图，产品白底图负责结构。
- 如果二者冲突，优先保护产品结构。
- 不要把分镜板中的文字卖点直接生成到视频画面里。
