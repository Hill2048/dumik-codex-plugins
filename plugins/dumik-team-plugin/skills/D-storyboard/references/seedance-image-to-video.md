# Seedance 图生视频参考

来源参考：MapleShaw/seedance2.0-prompt-skill，commit a2ab7fd。本文是 DUMIK 产品图生视频消化版。

## 使用边界

用于用户给首帧图、产品图、参考图，要求转成视频提示词。

只写提示词和分镜，不执行生成。执行仍交给 `D-video-run`。

## 核心原则

图生视频不要重写图片已有信息。文字只补四件事：

1. 时长和比例。
2. 主体动作。
3. 镜头运动。
4. 不允许改变的产品身份。

如果提示词过长，Seedance 更容易把图里的稳定信息冲掉。

## 时长下限

- Seedance 成片时长最短为 `4 秒`。
- 用户要求少于 `4 秒` 时，输出统一改为 `4 秒` 并说明调整；核心动作可在原指定时间窗内完成，剩余时间只做自然减速和结果停留。
- 不用新增动作、重复动作、循环播放或无意义切镜填满时长。

## 参考图角色

每张图必须命名角色：

- 首帧参考：控制视频第一帧。
- 产品结构参考：控制 SKU、轮廓、材质、关键部件。
- 场景参考：控制环境，不控制产品结构。
- 镜头参考：控制构图、机位、运动方向。
- 节奏参考：控制快慢、转场、动作力度。
- 声音参考：控制音色、节拍或环境声。

不要只写“参考上传素材”。

## 产品身份锁定

产品图生视频必须显式锁定：

- SKU 轮廓。
- 材质颜色。
- 尺寸比例。
- 把手、盖子、五金、边角、品牌区。
- 可动部件的运动路径。

禁止静默改变：

- 把手位置。
- 盖子形态。
- 金属/木材/玻璃材质。
- 品牌区大小和位置。
- 产品厚薄比例。

## 动作写法

每条视频只保留一个主动作：

- 产品缓慢旋转 20-30 度。
- 手部轻轻拿起后放回。
- 水流冲过表面。
- 刀具切过食材，产品保持稳定。
- 光线扫过材质纹理。
- 镜头推近到边缘细节。

避免：

- 同时旋转、切换场景、打开、冲洗、爆炸式特效。
- 让产品做不符合结构的动作。
- 让场景道具抢产品。

## 比例策略

- 用户指定比例优先。
- 首帧图作为整片画布时，视频比例跟首帧。
- 产品白底图只做结构参考时，不控制画布比例。
- 分镜板或多宫格只控制内部节奏，不自动控制整片比例。

产品电商默认：

- 短视频平台：9:16。
- 商品页或横版产品片：16:9。
- 单图确认片或素材延展：跟随首帧。

## 极简提示词模板

```text
比例：9:16，时长：5 秒。以@图片1为首帧，保持产品SKU轮廓、材质颜色、厚薄比例、品牌区和关键部件完全不变。画面中产品位于厨房台面中央，微俯视四分之三侧构图。镜头缓慢推近，水流轻轻冲过产品表面，突出表面易清洁和材质质感。结束时停在干净、完整、无变形的产品特写。禁止出现文字、水印、额外品牌、结构变形、把手/盖子/边角变化。
```

## 返修方向

- 产品变形：减少动作，强化结构参考，改为固定机位。
- 材质变脏：增加“材质颜色不变、表面纹理稳定”。
- 镜头乱：删掉多余运镜，只留推近或固定。
- 场景抢产品：删道具，压背景细节。
- 首尾不接：明确起始画面和结束画面。
