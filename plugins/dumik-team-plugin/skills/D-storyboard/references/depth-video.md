# 深度视频提示词规范

用于把黑白 Depth Map 视频作为运动与空间引导，生成真实实景视频。只写中文提示词，不在这里提交任务。

## Seedance 时长下限

- Seedance 深度参考视频提示词的总时长不得少于 `4 秒`。
- 用户要求少于 `4 秒` 时，自动改写为 `4 秒` 并明确说明；深度引导中的核心运动优先在原指定时间窗内完成，剩余时间沿同一轨迹自然减速并稳定停在结果画面。
- 补足时间不得新增镜头、重复深度运动、倒放、循环或改变空间轨迹。

## 分析顺序

先把深度视频当成摄影证据，不要直接把灰度画面改写成场景描述。

1. 读取实际时长、分辨率、帧率并覆盖首帧到末帧抽帧。
2. 先找硬切、叠化、遮挡转场或空间突变。切镜前后分别分析，不能把硬切误写成摄影机连续飞行。
3. 对快速推进、环绕、旋转、遮挡变化和结束段加密抽帧；必要时用局部运动向量或特征拟合辅助判断，但必须回到关键帧目视复核。
4. 再按下列维度提取：

   - 空间：近景、中景、远景的层级和遮挡关系。
   - 主体：人物轮廓、姿态、关节运动、朝向和位移。
   - 物体：数量、位置、大小关系和与主体的接触关系。
   - 构图：景别、机位、主体在画面中的占比和留白。
   - 摄影机：实体位移、推进或后退、升降、绕行、偏航、俯仰、光轴滚转、偏轴漂移和焦点变化。
   - 时序：动作何时缓起、加速、达到峰值、减速并停在哪里。

看不清的结构写“无法确认”，不要从灰度猜人物身份、服装颜色或环境材质。

## 运镜拆解门禁

- 每个镜头先写一条主轨迹，再写同时发生的运动分量。推进时仍在旋转，就必须写成“推进与旋转同步发生”，不能只保留推进。
- 旋转必须注明轴线：绕主体的空间环绕、围绕垂直轴的方位变化，或沿镜头光轴的滚转。
- 旋转方向优先用观众画面口径描述，例如“锅沿参照物围绕锅心顺时针移动”；若补充摄影机本体方向，要明确是等效方向，避免正反写反。
- 通过主体占比变化、边缘扩张和近远景视差判断实体推进；不要仅凭画面变大就断言是焦距变焦。
- 速度必须按时间段表达。旋转和推进可以不同步收速，例如“旋转先减速，推进继续”。
- 只有证据足够时才写角度、倍率或每秒速度；否则写相对变化，不制造伪精度。
- 深度图纹理弱、局部运动估计互相矛盾时，以跨帧稳定参照物、轮廓变化和成片对照为准，并标记无法确认的分量。

逐段记录：

```text
时间段 / 剪辑点：
摄影机起点与终点：
主轨迹与观看目标：
同步运动分量：
旋转轴与画面方向：
推进倍率 / 主体占比变化：
前中后景视差与偏轴漂移：
速度曲线：
结束状态：
证据与不确定项：
```

## 角色优先级

- `depth_video`：只控制空间、姿态、位置、遮挡、构图、镜头轨迹和动作时序。
- `identity_image`：控制人物身份、服装、产品结构或指定物体外观。
- 用户文字：控制真实环境、材质、色彩、光线和电影风格。

深度视频不控制颜色和材质，也不能把结果做成黑白深度图。

## 最终模板

```text
比例：{比例}，时长：{时长}秒。

depth_video：黑白深度引导视频，只控制空间纵深、人物姿态、物体位置、遮挡关系、画面构图、动作时序和摄影机轨迹；其中摄影机轨迹包含实体位移、观看方向修正、旋转轴、画面旋转方向、推进关系、偏轴漂移、视差和非线性速度曲线，不控制颜色、材质与最终视觉风格。
{有身份参考时：identity_image：控制人物身份、服装或产品外观，不改变 depth_video 的空间与运动。}

以 depth_video 作为深度引导，严格保持其中的近中远层级、主体轮廓与姿态、物体相对位置、遮挡关系、剪辑点、镜头轨迹和构图。将抽象深度结构转化为真实实景拍摄：{真实人物/产品/场景}，还原真实环境材质、自然光影和写实电影质感。

按时间线执行摄影机：{逐段写明起点、终点、主路径、同步运动分量、旋转轴与方向、推进、偏轴、视差、缓起、加速、峰值、减速和停留}。同时发生的推进、平移、升降、环绕、偏航或滚转必须保持同步，不得拆成先后动作或省略其中一项。人物动作与场景布局逐帧匹配深度信息，直到结尾不发生空间漂移。

约束：不要生成黑白深度图、伪彩深度图或扫描效果；不要改变人物姿态、物体数量与位置、真实剪辑点、镜头方向和构图；不要把复合运镜粗化成数字缩放，不要在推进时停止原有旋转，不要新增无关主体，不要肢体崩坏、穿模、闪烁、漂移或背景跳变。
```

## 精简模板

没有额外身份图且用户只给真实化方向时，直接使用：

```text
比例：{比例}，时长：{时长}秒。

depth_video：黑白深度引导视频，只控制空间纵深、人物姿态、物体位置、画面构图、动作时序和镜头移动轨迹。

以 depth_video 作为深度引导参考，严格遵循其中的空间纵深、人物姿态、物体位置、镜头移动轨迹和画面构图；将抽象深度结构转化为真实实景拍摄视频，呈现写实电影质感、真实环境材质和自然光影。人物动作、场景布局和镜头运动持续匹配深度信息，画面流畅稳定，不崩坏、不漂移。

约束：不要保留黑白深度图外观，不要改变姿态、位置、构图和镜头轨迹，不要穿模、闪烁、肢体崩坏或背景跳变。
```
