# 视频故事板与分镜提示词

视频工作的唯一故事板和逐镜提示词入口。旧的产品故事板和连续分镜两个入口已合并为一套逻辑。

默认只输出提示词、分镜、关键帧和逐镜视频提示词。不调用生图、生视频或 CLI。只有用户明确说“生成 / 出图 / 出片 / 提交 / 跑任务”时，才交给 `D-image-run` 或 `D-video-run` 执行。

可直接套用的模板块（Image2 身份板、故事板生图模板、逐镜模板、线性序列）在 [references/templates.md](references/templates.md)，写之前先读对应块。

当用户要求高级感广告、TVC、品牌片、电影感、导演感、真人实景、剧情短片或反 AI 质感时，读取 [references/cinematic-commercial-staging.md](references/cinematic-commercial-staging.md)。它是所有模式都可启用的增强层，不是第四种模式。

Seedance / Dreamina 相关参考：

- 镜头语言和运镜控制：读 [references/seedance-camera-codec.md](references/seedance-camera-codec.md)。
- 产品图或首帧转视频：读 [references/seedance-image-to-video.md](references/seedance-image-to-video.md)。
- 分镜板、多宫格、故事板参考图转视频：读 [references/seedance-storyboard-driven.md](references/seedance-storyboard-driven.md)。
- 黑白深度视频转真实实景视频：读 [references/depth-video.md](references/depth-video.md)。

这些参考只补强提示词写法，不改变本 skill 的边界：不提交生图、生视频或 CLI。

## Seedance 时长下限

- Seedance 视频提示词的总时长不得少于 `4 秒`。
- 用户要求 `1-3 秒` 时，自动改写为 `4 秒`，并在交付时明确说明已按平台下限调整，不能继续输出低于下限的时长。
- 核心动作仍优先在用户指定的时间窗内完成；补足的时间只用于同一镜头自然减速、稳定停留或保持结果，不新增动作、不切镜、不循环。
- 时间轴、分镜表、首尾帧说明和最终提示词中的总时长必须同步改为 `4 秒`，不得只改标题或单个字段。

## 何时使用

- 产品故事板、Image2 故事板、产品身份板、产品视频分镜。
- 分镜、连续镜头、关键帧、镜头语言、视频 AI 序列提示词。
- 每个镜头的生视频提示词、首帧 / 尾帧提示词、故事板生图提示词。
- 深度视频、Depth Map 视频、黑白深度引导视频转真实实景视频。

用户只要卖点顺序、内容策略或 30-60 秒结构时，先走 `D-video-plan`，再回来做视觉分镜。

## 核心原则

产品故事板和连续分镜共用同一套底层逻辑：

1. 先锁稳定锚点。
2. 把视频拆成可见阶段。
3. 相邻格保持衔接。
4. 每镜只给一个主动作和一条可解释的摄影机轨迹。一条轨迹可以同时包含推进、平移、升降、环绕、摇移或光轴滚转；只要这些分量共享同一目标、空间轴线和速度曲线，就不是“多个镜头动作打架”。
5. 定义起始画面、运动、环境变化、结束画面。
6. 跨图片、故事板、生视频保持身份一致。
7. 商业目标与电影质感可以同时成立：用真实调度、物理光色和可信材质提高产品价值，不把“高级广告”误写成反广告。

product 模式额外加强身份约束：SKU、轮廓、结构、材质、颜色、比例、把手/盖子/五金、品牌区、不可改特征。

## 有视频输入时先看完整段

只要用户提供视频，并要求基于视频写脚本、分镜或提示词，写作前必须完整检查从首帧到末帧的整段视频。

1. 先读取视频的实际时长、画面比例、帧率和音轨信息。
2. 默认不要完整播放。优先按视频时长自适应抽帧并制作联系表，生成后必须实际打开查看。抽帧须覆盖从首帧到末帧的完整时间轴；对转场、快速动作、遮挡变化和最终帧再局部加密抽帧。只有用户明确要求完整播放，或抽帧无法判断任务所需的连续动作、声音节奏时，才完整播放视频。
3. 按真实时间顺序记录每个镜头的起止时间、主体动作、运镜、转场和结束状态。提示词中的时间段必须来自这份实际时间线，不能凭印象补写。
4. 运镜不能只记一个动词。逐段拆出摄影机实体位移、观看方向修正、旋转轴与画面旋转方向、推进倍率、偏轴漂移、前中后景视差和速度曲线；同时发生的运动必须写在同一时间段内。先找真实切点，再分别分析各镜内部轨迹，不能把硬切误写成连续绕飞。
5. 任务涉及口播、声音节奏或屏幕文字时，同时完整听取或转写相关音轨，并核对文字出现与消失的时间。
6. 视频无法完整读取、解码中断或末段尚未检查时，明确说明当前缺口；不得声称已经看完，也不得据此输出假定完整的最终提示词。

完成以上检查前，不输出声称基于该视频的最终提示词。

## 模式选择

静默选择，在输出头部注明：

- `product`：产品、商品、SKU、主图、详情页、材质、品牌区、产品故事板、Image2。
- `sequential`：人物、场景、剧情、氛围片、连续镜头、非产品分镜。
- `hybrid`：产品在生活场景里被使用、产品广告片、产品 + 人物动作、产品 + 场景叙事。

拿不准用 `hybrid`，画面里有真实产品就保留产品身份约束。

## 输出块

默认输出：1) 视频模式与目标；2) 稳定锚点表；3) 故事板 / 连续分镜提示词；4) 分镜拆解表；5) 逐镜生视频提示词；6) 返修检查点。需求窄时只出用户要的块。

## 稳定锚点

写格子之前必须先立锚点：

```text
视频目标：
模式：product / sequential / hybrid
主体：
主体身份锚点：
外观结构 / 角色特征：
材质颜色 / 服装道具：
场景与空间逻辑：
光线与色调：
高级商业电影增强：开启 / 关闭
可见障碍或观看理由：
观众位置 / 摄影机立场：
物理光源与色彩来源：
运动节奏：
摄影机实体轨迹 / 旋转轴 / 方向：
速度曲线 / 视差 / 偏轴变化：
整体比例：16:9 / 9:16
单格分镜比例：默认 3:4
分镜数量：
不能改变的特征：
禁止出现：
```

product 扩展：产品名称、品类、核心卖点（最多 3 个按画面优先级）、关键部件、品牌区、可动状态、使用场景、产品身份参考。

电影增强开启时，角色只保留少量稳定识别锚点；产品结构锚点不得因此删减。人物连续性追求少而准，产品连续性追求足以证明是同一 SKU。

## 故事板生图提示词规则

提示词里写：画布/排版（如 `12 格视频故事板，3 列 × 4 行`）、参考图角色、画面语言、逐格可见动作节点、最小风险控制。

提示词里不写：文件路径、上传步骤、命令、输出目录、模型名、API key、`输出规格`/`4K` 等执行参数、长执行说明或营销文案。

比例规则：`16:9` 横版用于网站视频和产品片；`9:16` 竖版用于电商和短视频平台；`3:4` 是默认单格比例，不是默认整板比例。产品电商默认：整板 `9:16`，单格围绕 `3:4` 构图。

## 分屏镜号与独立镜头

- 三联、四宫格、九宫格、十二格及其他分屏拼版，每一格都必须按阅读顺序标注两位镜号：`SHOT 01`、`SHOT 02`……不得只写数字、漏标或重复。
- 镜号固定在每格左上角安全区，白字配半透明黑色矩形底，尺寸清楚但不抢画面主体；不同格的字号、边距和底色样式保持一致。
- 镜号属于拼版标注层，不得烧录进独立镜头源图。
- 独立镜头、首帧、尾帧和用于生视频的垫图保持干净：不加 `SHOT`、序号、字幕、说明文字、箭头、边框或水印。
- 若先生成独立镜头再外部拼版，保留干净源图，只在最终拼版的每格左上角添加镜号。
- 除镜号外，规划故事板可按用户要求克制使用细运动箭头、构图框和时序数字；不要廉价贴纸箭头、发光轨迹、重 HUD、蓝图风、营销文字、水印或乱码。

区分两种交付：

- `规划故事板`：允许一次生成一张完整九宫格，服务讨论、节奏规划和分镜板驱动视频；未指定分辨率时默认 `4K`。
- `生产关键帧`：每镜独立出图且不带镜号，未指定分辨率时每张默认 `2K`，再外部拼版；不得要求图像模型直接生成拼贴。这样才能单镜补跑、保持清晰度并准确替换失败镜。外部拼版必须按上述规则给每格添加 `SHOT NN`，独立源图不变，不重新生成镜头，也不静默升档。
- 分辨率属于执行参数，不写进故事板生图提示词正文；用户明确指定尺寸时以用户要求为准。

## 承接上一张故事板

依赖上一张故事板时，上一张选定的故事板图必须作为真实参考传入：

- 参考名 `@PREV_STORYBOARD_REF`，只控制首格的主体位置、光向、焦点、场景延续和上一板的结束状态。
- 执行工具传不了上一张图时，不许承诺“继承上一张”；明说连续性会变弱，改写成纯文字连续性。

## 逐格规则

每格必须有：主体；距离/视点/机位；镜头运动或固定状态；环境光线氛围；与上一格相比的一个可见变化。

电影增强开启时，每镜再明确：一个主要动作或产品证据、一个次要线索、摄影机为何在这里、观众处于什么立场、视线入口/落点/出口、光与颜色的现实来源。不要为了“电影感”堆满前景、烟雾、颗粒、镜头光斑和空泛形容词。

连续性：整个序列是同一个世界，不出无关海报；产品身份、角色身份、材质、空间、光线、色调稳定；相邻格要有差异但不破坏连续；连续不等于重复。

运动：一个主体主动作 + 一条摄影机主轨迹。复合轨迹可以在同一时段同步发生，例如“弧形右移时轻推近并向主体偏航修正”或“向锅心俯冲时持续沿光轴旋转”；必须写清各分量的共同目标、轴线、方向、先后和速度曲线。禁止把真实复合运动粗化成单一“拉近”，也禁止堆叠彼此无关、会让镜头乱飞的动作。

## 分镜拆解表

故事板定稿或生成后，把每格拆成可执行字段：

```text
镜头编号：
画面目标：
镜头功能：认知 / 疑问 / 证据 / 决定 / 后果 / 记忆，或对应剧情功能
观众位置：摄影机为何在这里
构图压力：主体被什么关系、空间或物体影响
关键证据：本镜必须被看见的唯一信息
起始画面：主体位置、景别、构图
主体动作：只保留一个主动作
摄影机实体轨迹：机位从哪里到哪里，围绕什么目标或轴线
同步运动分量：推进 / 平移 / 升降 / 环绕 / 摇移 / 滚转，哪些同时发生
旋转方向：明确以摄影机本体或观众画面为准，避免方向写反
速度曲线：缓起 / 加速 / 峰值 / 减速 / 惯性停留，对应时间点
空间反馈：前中后景视差、主体占比、偏轴漂移和焦点变化
环境变化：只保留一个辅助变化
结束画面：最后停在哪里
视线流量：入口 -> 阻断/减速 -> 落点 -> 出口
与前镜变化：景别、机位、距离、观看立场、焦点层、光向或人物状态
连续性依赖：上一镜 / 下一镜 / 无
生视频注意事项：
```

某格看不清就写 `需重画该格`，不要编造缺失的视觉事实。

## 逐镜生视频提示词

一镜一条提示词，不把多个无关镜头塞进一条。模板见 `references/templates.md`（product/hybrid 版和 sequential 版，外加单条线性序列写法）。

Dreamina / Seedance 默认：按 `seedance2.0` 的稳定性写；只有用户明确要快才用 `seedance2.0fast`；目标工具不能选模型时省略模型参数，保持工具无关。

写 Seedance 提示词时，优先使用 DUMIK 消化版参考：

- 每镜只保留一个主动作和一个镜头运动。
- 图生视频时少重述画面已有内容，只补时长、比例、动作、镜头和产品身份锁定。
- 分镜板驱动时必须写明不复刻边框、网格线、格子编号、注释文字或水印。
- 产品白底图控制结构，故事板控制动作和构图；二者冲突时保护产品结构。
- 有参考视频时，提示词必须保留证据中同时发生的运动分量。例如推进期间仍在旋转，就写成同一条连续螺旋或弧线轨迹，不能拆成“先旋转、后拉近”。
- 对旋转同时标注观察口径：优先写“以观众看到的画面为准，参照物顺/逆时针移动”；需要描述摄影机本体时再补充等效滚转方向。
- 非线性运动按时间段写缓起、加速、峰值、减速与停留；没有证据时不编造角度、倍率或速度数值。

## 深度视频模式

深度视频不是风格参考。先从真实视频逐帧提取近中远层级、人物轮廓与姿态、物体位置、遮挡关系、构图和镜头移动轨迹，再把这些结构写成可执行的中文提示词。

- 深度视频控制：空间纵深、人物姿态、物体位置、遮挡、镜头轨迹、画面构图和动作时序。
- 身份图控制：人物身份、产品结构、服装和具体外观。
- 用户文字控制：真实场景、材质、色彩、自然光影和电影质感。
- 不继承深度图的黑白灰外观、伪彩、噪点、轮廓断裂或深度可视化质感。
- 深度结构与身份外观冲突时，保持深度视频的空间和运动，保持身份参考的外观，不互相越权。
- 深度视频出现复合运动时，必须分别识别位移、推进、旋转、偏轴与速度曲线，再合并为同一条物理轨迹；不得只写“跟随深度视频运镜”。

最终提示词使用 [深度视频模板](references/depth-video.md)，开头必须注明比例、时长和 `depth_video` 的作用；不写“参考上传素材”这种模型无法区分角色的说法。

## 返修诊断

- 主体漂移：回到身份锚点 / 产品身份板。
- 动作错误：改对应格或单镜提示词。
- 镜头乱飞：先判断多个分量是否属于同一条物理轨迹；删除相互冲突的动作，而不是删掉参考视频里真实存在的同步旋转、推进或偏航修正。
- 画面太杂：收紧环境和道具。
- 产品结构变化：加强不能改变的产品特征。
- 故事板不可接：补起始画面、结束画面、上一镜依赖。
- 标注廉价：只保留专业细箭头、构图框和克制序号。
- 分屏镜号缺失或样式错误：按阅读顺序补齐 `SHOT 01` 起的两位镜号，统一放在每格左上安全区，使用白字和半透明黑底。
- 独立垫图带镜号：清除镜号及所有版面标注，保留干净源图；需要展示时另做带镜号拼版。
- 画面像廉价广告模板：删掉油亮表面、无来源轮廓光、全局金黄/青橙、英雄摆拍和平均照亮；保留商业目标，用真实材质、决定性证据和克制调度重做。
- 画面“反广告”但不卖货：恢复产品是什么、解决什么、证据在哪里、最终记住什么；电影语言必须增强转化，不能遮住产品。
- 镜头可以随意调换：补清前因、产品介入、证据和后果，不用风格变化冒充叙事推进。

## 高级商业质量门

交付前检查：

- 商业目标是否清楚，产品或品牌价值有没有被电影化表达增强。
- 关键卖点是否通过动作、结构、材质或结果被看见，而不是靠字幕解释。
- 摄影机位置、光源、色彩和前景是否有功能，不是装饰。
- 镜头顺序是否形成认知或因果推进；相邻镜头是否既连续又有真实变化。
- 人物、产品、道具、空间和光线是否稳定；产品结构与品牌区是否准确。
- 画面是否避开廉价广告模板、CG 游戏感、蜡质皮肤、过度 HDR、无来源特效和平均精致。
