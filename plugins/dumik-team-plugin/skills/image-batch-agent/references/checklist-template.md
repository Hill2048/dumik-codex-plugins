# 批量改图项目模板

开始前先确认：

```text
项目名：
本次要改什么：
输出路径：
每张生成几张：2
参考图作用：
图片模型：gpt-image-2 / banana2
API：默认读取本机缓存；特殊情况再填
```

创建项目目录后，只保留三个文件夹：

```text
<项目目录>\
  原图\
  参考\
  输出\
```

用户把图片放好后，再把每张原图整理成下面这种结构，每张图单独一条：

```text
- 文件名: 001.jpg
  改动: 保持产品角度和结构不变，背景改纯白，去掉杂物，金属边缘更干净
  比例: 保持原图
  必须保留: 产品结构, 品牌区, 主体角度
  参考图: 参考/ref-材质.jpg 控制材质
  count: 2
  output_name: 001.png

- 文件名: 002.png
  改动: 保留瓶身和品牌文字，改成高级浴室场景，光线更柔和，增加一点水汽氛围
  比例: 保持原图
  必须保留: 瓶身轮廓, 品牌文字, 瓶盖比例
  参考图: 参考/bathroom-lighting.jpg 控制浴室光线与空间氛围
  count: 2
  output_name: 002.png
```

如果用户只给统一需求，默认补全规则：

- 比例：保持每张原图视觉比例。
- 必须保留：产品结构、品牌区、主体角度、把手、盖子、五金、轮廓和 SKU 比例。
- 参考图：按用户说明分配为材质、风格、构图、产品结构或局部细节参考。
- count：2。
- output_name：用原文件名主干加 `.png`。

确认图阶段只取第一张原图，`count` 固定为 `1`，`output_name` 放到 `确认图/` 下。
