# 工作流 4｜电商视频转化链路规划

## 适用场景
用于在做分镜前，先把视频的转化逻辑排对。

典型触发词：
- 主图视频结构
- 卖点排序
- 转化链路怎么排
- 先讲什么后讲什么
- 30秒 / 45秒 / 60秒 视频框架
- 现有脚本太平，帮我重排
- 先不要写分镜，先定逻辑

## 核心目标
不是把所有卖点平铺，而是决定：
- 什么必须先讲
- 什么可以延后
- 什么应该删除
- 什么证据应该紧跟出现
- 最后观众记住什么

## 决策优先于表达
先做：
- 产品定义
- 模块顺序
- 卖点优先级
- 信任建立路径

后做：
- 分镜
- 镜头运动
- 文案句式
- 音乐节奏

## 第一步：先判断投放位置
### 主图 / 列表页视频
- 追求快速认知和快速信任
- 模块要压缩
- 一个模块通常只干一件事

### 详情页视频
- 可容纳更多解释
- 可在后段补充次级功能

### 广告 / 投放视频
- 钩子更强
- 但仍不能盲目堆卖点

### 内容型 / 社媒型视频
- 若目标更偏内容和叙事，不强行套硬电商结构

## 五种转化驱动力
### 1. 认知 Cognition
当用户先要明白“这是什么、和普通有什么不同”时优先。

### 2. 信任 Trust
当主卖点容易被怀疑时优先。
例如：安全、健康、0残留、医用级、婴童适用、实验室认证。

### 3. 使用快感 Usage Pleasure
当产品价值在动作中一眼可见时优先。
例如：更顺滑、更轻、更稳、更省力。

### 4. 差异化 Differentiation
当竞品看起来都差不多时优先。

### 5. 品牌收束 Brand Closure
通常放最后，用来留下记忆。

## 判断顺序的关键问题
1. 观众首先必须理解什么？
2. 接下来最可能怀疑什么？
3. 需要什么视觉证据消除怀疑？
4. 哪个使用收益最值得被记住？
5. 结尾应该留下什么品牌记忆？

## 压缩规则
- 短视频里，一个模块通常只承担一个任务
- 不要让一个模块同时定义、证明、比较、演示、收尾
- 少而强，优于全而散

## 保留/删除判断
一个卖点至少满足以下之一才值得留下：
- 能改变观众的相信顺序
- 能带来可见使用差异
- 能让产品从竞品中被分开
- 能加强品牌或品类记忆

若只是“多一条信息”，但不改变信念和行动，优先压缩或删除。

## 默认输出结构
1. 当前视频的核心转化障碍
2. 推荐转化链路
3. 模块顺序表
4. 每一模块的任务说明
5. 应删减 / 后置 / 弱化内容
6. 若用户要继续，可再输出分镜方向

## 与分镜模式的衔接
当用户继续要分镜时：
- 先保留本链路不变
- 再把每个模块翻译成镜头段落
- 分镜不能推翻转化顺序
