# 工作流 5｜连续分镜 / 视频 AI 顺序提示词

## 适用场景
用于把一个镜头概念扩展成多段连续分镜或视频 AI 线性描述。

典型触发词：
- 分镜提示词
- 四格分镜
- keyframe prompt
- sequence prompt
- storyboard
- 连续镜头描述
- 视频 AI 顺序提示词

## 核心目标
把一个画面想法拆成连续、可见、可拍、可生成的一组镜头块。

重点不是“写四段很像的话”，而是：
- 保持产品与世界一致
- 建立一条连续镜头路径
- 每一格都出现新的可见发现
- 输出可直接复制使用

## 默认流程
1. 先锁定稳定锚点
- 产品身份
- 形体
- 材质
- 光线
- 色调
- 空间逻辑

2. 再拆成两类
- 必须稳定的部分
- 可以变化的部分（机位、距离、前后关系、道具位置、节奏）

3. 先输出开头设定
固定三行：
- 提示词作用
- 产品描述
- 画面设定

4. 再输出分镜块
- 用户指定结构就跟随用户结构
- 用户没指定时，默认 2x2 四格

5. 最后加一个“视频AI顺序描述”
把同一组内容改写成单镜头连续运动描述

## 写法要求
### 每一格都必须包含
- 主体
- 景别 / 视角 / 观看位置
- 镜头动作或停留状态
- 环境 / 光线 / 气氛
- 相比上一格新增的可见变化

### 连续性优先
所有格子必须是同一支镜头里的阶段，不是四张互不相干的海报。

### 用画面语言表达“保持不变”
优先写成：
- 沿用同一厨房空间、同一米白台面和同一柔和侧光
- 两个版本共用同一锅身和手柄比例
- 暖棕背景继续保持细腻无木纹哑光硬质面

少写长篇“不要、禁止”。

### 运动语言克制
常用动作：
- 滑入
- 推近
- 掠过
- 偏移
- 轻微抬升
- 压向核心区
- 减速停住
- 稳定悬停

通常一个主动作 + 一个辅助变化就够了，不要每格都很花。

## 输出模式
### 默认 plain text
用两个独立代码块输出：
1. 主分镜块
2. 视频AI顺序描述

### 用户明确要 JSON 时
只输出合法 JSON，不包 markdown。

## 默认模板
```text
提示词作用：这组提示词用于动态画面的顺序分镜。
产品描述：…
画面设定：…

[结构标签1]
…

[结构标签2]
…
```

```text
视频AI顺序描述
先… 接着… 然后… 最后…
```

## 质量标准
- 产品身份、材质、空间、光线必须稳定
- 相邻镜头必须明显不同，但不丢失连续性
- 连续不等于重复
- 变化不等于跑偏
