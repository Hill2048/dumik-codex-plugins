# 工作流 1｜图片改图提示词

## 适用场景
用于已有图片基础上的改图、修图、风格对齐、白底图升级、场景证据补强、动作瞬间写实化。

典型触发词：
- 改图工具
- 改图 prompt
- 修图提示词
- 按图1风格优化
- 参考图风格迁移
- 白底图高级感优化
- 保持角度不变
- 不要改产品

## 核心目标
输出严格、可直接粘贴的图片编辑指令，而不是泛泛建议。

## 先做的判断
### 1. 先判断图片角色
- 必须先明确每一张图的作用，再开始写改图指令
- 必须明确写出“本次实际要修改的图是哪一张”
- 多张图同时出现时，不允许把所有图都当目标图，必须逐张判断
- 目标图逐张输出，不混写

#### 图片角色定义
- 目标图：实际要被修改、修复、替换、增强的图片
- 参考图：用于提供风格、材质、光线、构图、氛围、反射、色调等参考的图片
- 局部替换素材图：用于提供某个局部元素的图片，例如徽章、logo、把手、标签、文字牌、包装件、零部件
- 结构依据图：用于校正工业设计、轮廓、比例、连接关系、真实产品细节的图片
- 细节依据图：用于补充纹理、材质肌理、金属处理、木纹、玻璃状态、边缘做工的图片

#### 默认判断规则
- “图1按图2优化 / 图1参考图2优化”＝图1是目标图，图2是参考图
- “图1改成图2的感觉 / 参考图2的质感优化图1”＝图1是目标图，图2是参考图
- “图1的徽章换成图2”＝图1是目标图，图2是局部替换素材图
- “把图2按照图1修复”＝图2是目标图，图1是参考图或结构依据图
- “图1参考图2，再把右下角标换成图3”＝图1是目标图，图2是整体参考图，图3是局部替换素材图
- 若用户说“修改这张 / 修这张 / 这张按另外几张参考”，则“这张”优先判定为目标图，其余为参考或素材图
- 若用户表达模糊，优先根据句子主语判断；句子主语通常就是目标图

### 2. 先判断模式
#### 锁定模式
适用于：
- 保持产品结构不变
- 保持角度不变
- 保持构图不变
- 不要改产品
- 白底图优化
- 只修质感 / 光线 / 背景

要求：
- 严格保留目标图产品结构、角度、构图、比例和细节
- 只优化光线、背景、材质层次、空间证据和真实感

#### 创意模式
适用于：
- 更像广告
- 更有创意
- 做 KV
- 重构画面
- 增加故事感
- 场景化

要求：
- 产品可识别性必须保留
- 环境、氛围、动作、空间层次可以增强
- 不得把产品改成不同 SKU

若用户表达模糊，默认锁定模式。

### 3. 先判断图像类型
- 白底图精修
- 场景证据升级
- 动作瞬间写实
- 产品主导叙事写实

### 4. 先判断目标图比例
- 先识别目标图原始宽高关系
- 再从标准比例池中匹配最接近的比例
- 标准比例池固定为：1:1、1:4、4:1、1:8、8:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9
- 新增支持超长竖幅与超长横幅：1:4、4:1、1:8、8:1
- 若用户已明确指定比例，则优先服从用户指定，不再自行判断
- 锁定模式下，优先保持原图视觉比例不被明显改动
- 创意模式下，可在不破坏主体构图与产品完整性的前提下收束到最接近的标准比例

## 写法原则
### 1. 先写精简修改说明
2～4 条短 bullet，说明本次主要改什么。

### 2. Prompt 结构顺序固定
1. 画面比例
2. 图片角色判断
3. 精简修改说明
4. 图片编辑指令

### 3. 真实感不能空泛
优先用可见证据来证明真实，而不是只写“更真实”。

可用证据：
- 电磁炉触控面板
- 台面边缘
- 墙面明暗过渡
- 柜体虚化
- 油膜反应
- 锅内局部热感
- 少量食材已落入，少量仍在空中
- 柔和接地阴影

### 4. 产品主导
- 场景只作辅助
- 不做教程拼贴感
- 不做拥挤生活方式图

## 默认输出格式
```markdown
## 图[X]

### 画面比例
- 原图视觉比例：约为 [识别结果]

- 比例处理原则：[保持原构图 / 轻微收束到标准比例 / 服从用户指定比例]

## 默认风格底盘
未特殊说明时默认：
- 柔和自然侧光
- 暖中性或奶白背景
- 阴影过渡柔和
- 金属高光真实克制
- 玻璃反射克制
- 涂层颜色低饱和高级
- 商业摄影质感，不锐化过头

## 输出约束
- 画面比例必须写在最前面
- 必须明确每张图的作用，并对应到具体图号
- 必须明确“本次实际修改对象”
- 不允许只写“竖版 / 横版 / 方图”，必须落到具体比例
- 若图3仅用于局部替换，也必须写明“图3仅提供局部元素，不是整体风格参考”
- 若同时存在整体参考与局部参考，必须拆开写，不能混为一个角色
- 比例判断服务于改图执行，不得因为套标准比例而破坏主体构图

## 禁止事项
- 不输出其他平台 prompt
- 不把修图任务写成生图任务
- 不擅自改变手柄、锅盖、五金、品牌区、SKU 比例
- 不把真实感理解成堆道具
- 不省略图片角色判断
- 不省略“本次实际修改对象”
