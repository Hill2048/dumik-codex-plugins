# 改图边角参考（原 super-image-prompt 留存）

主规则、输出三段式、比例、约束写法都在 SKILL.md，这里不重复。只留它没细讲的两块：怎么判断每张图的角色、默认风格底盘。统一用 `image1 / image2 / image3...` 编号，按上传顺序。

## 怎么判断每张图是谁

多图时先把每张图对上 image1 / image2 / image3，再写词。常见说法对应：

- “image1 按 image2 优化 / image1 参考 image2” → image1 目标图，image2 风格或材质参考。
- “image1 改成 image2 的感觉” → image1 目标图，image2 参考图。
- “image1 的徽章换成 image2” → image1 目标图，image2 局部替换素材（只供那个局部）。
- “把 image2 按 image1 修复” → image2 才是目标图，image1 参考或结构依据。
- “image1 参考 image2，右下角标换成 image3” → image1 目标图，image2 整体参考，image3 局部替换素材。
- “修这张 / 这张按另外几张参考” → “这张”就是目标图，其余是参考或素材。
- 说不清就看句子主语，主语通常是目标图；还是分不清先问。

角色就这几种：目标图（实际被改的那张）、风格参考、材质/细节依据、结构依据、局部替换素材。整体参考和局部替换一定分开写，别混成一个角色。

## 真实感靠可见证据，不靠形容词

要“更真实”就给画面能看见的东西，别堆“高级 / 真实 / 有质感”。炊具场景常用证据：电磁炉触控面板、台面边缘、墙面明暗过渡、柜体虚化、油膜微反光、锅内局部热感、少量食材已落入少量还在空中、柔和接地阴影。产品永远是主角，场景只托底。

## 默认风格底盘（没特别要求时）

柔和自然侧光、暖中性或奶白背景、阴影柔和过渡、金属高光真实克制、玻璃反射克制、涂层低饱和高级、商业摄影质感不过锐。

## 默认锁定

表达模糊时默认锁定模式：保结构、角度、构图、比例、SKU，只动光线 / 背景 / 材质层次 / 真实感。要广告化重构再切创意模式，但产品必须可识别，不能变成另一个 SKU。
